# LunaCare — UI/UX Design Project

## Project Overview

LunaCare is a user-friendly menstrual cycle tracking mobile application
designed to help users track their menstrual cycle and understand
their cycle-related information.

## My Role

UI/UX Designer

## Tools Used

- Figma
- FigJam

## Design Process

1. User Research
2. User Persona
3. Mind Mapping
4. User Flow
5. Wireframing
6. UI Design
7. Prototyping
8. Usability Testing

## Key Features

- Menstrual cycle tracking
- Cycle information
- Health insights
- AI Health Assistant
- User-friendly interface
- Mobile application design
